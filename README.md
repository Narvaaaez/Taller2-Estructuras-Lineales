## Descripción

Los ejercicios están organizados dentro del paquete `Recursividad` en la carpeta `src`.

## Cómo ejecutar

Desde la carpeta raíz del proyecto, compilar los archivos con:

```bash
javac -d out src/Recursividad/*.java
```

Después de compilar, cada ejercicio puede ejecutarse individualmente.
